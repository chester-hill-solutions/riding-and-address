# CanCoder interface guidelines

Keep CanCoder’s blue palette, serif display type and address/grid identity.

Never add decorative coloured top borders or accent stripes to cards, panels or dialogs. This includes the rounded-card top stripe previously used on login and signup. Use typography, spacing, surface colour and restrained shadows for hierarchy. Neutral separators and accessible focus indicators are appropriate where functional.

Use the shared portal components and relative links for site navigation. New upload and payment screens follow the same rules.
